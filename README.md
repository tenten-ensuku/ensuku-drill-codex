# エンスクドリル

麻雀の「形」を反復練習するためのブラウザアプリです。

6枚形、7枚形、10枚形の牌姿を見て、正しい受け入れ牌や待ち牌を選びます。  
タイムアタック、裏モード、復習、お気に入り、問題一覧、自己分析、ランキング投稿に対応しています。

公開URL:

https://tenten-ensuku.github.io/ensuku-drill-codex/

## 主な特徴

- 6枚形、7枚形、10枚形の形判断を練習できます。
- 萬子、筒子、索子、左右反転、数字シフトによって、丸暗記ではなく形そのものを覚える設計です。
- 表モードのほか、ミスした瞬間に終了する裏モードがあります。
- 間違えた問題は復習に自動追加されます。
- 気になる問題はお気に入りに保存できます。
- 問題一覧から、問題ごとの正答率を確認できます。
- 自己分析で、日別ベスト推移やモード別成績を確認できます。
- ランキング投稿に対応しています。
- ボタンサイズ、ボタン位置、数字配列、音量、ニックネームを設定できます。

## モード

### 六枚形

2面子完成となる受け入れ牌を選ぶ練習です。

実戦での出現頻度が高い形を、素早く正確に処理できるようにすることを目的にしています。

### 七枚形

表示された牌姿が何待ちかを選ぶ練習です。

多面待ちや一色手の形判断に慣れるためのモードです。

### 十枚形 20問 / 80問

より実戦に近い長めの牌姿を扱います。

複数の形が絡んだ状態で、どこが面子、雀頭、待ちとして残るのかを整理する練習です。

### 裏モード

条件を満たすと開放される高緊張モードです。

ミスするとその時点でゲームオーバーになります。  
正確性を保ったまま速度を上げたい人向けです。

## 機能

### 復習

タイムアタック中に間違えた問題が自動で保存されます。  
あとからまとめて解き直せます。

### お気に入り

気になる問題を保存できます。  
復習タブ内からまとめて練習できます。

### 問題一覧

6枚形、7枚形、10枚形の問題一覧を確認できます。  
問題ごとの正答率も表示されるため、苦手な形を把握できます。

### 自己分析

モード別に以下のような成績を確認できます。

- 総プレイ回数
- 今日のプレイ回数
- 最高ランク
- 平均正答率
- 平均秒/問
- 日別ベスト推移
- 苦手な形

日別ベスト推移は、初期、直近、全期間を切り替えて確認できます。

### 順位

Cloudflare Workers + D1 を使ったランキング機能です。
設定で決めたニックネームで投稿されます。

## 開発メモ

このアプリは、GitHub Pages で公開している静的なシングルページアプリです。

主要ファイル:

- `index.html`: アプリ本体
- `tiles/`: 麻雀牌画像
- `assets/`: ロゴ、演出画像など
- `ranking-worker/`: ランキングAPI、D1スキーマ、移行・検証スクリプト
- `ranking-worker/README.md`: ランキングの運用・バックアップ・切り戻し手順
- `supabase-*.sql`: 旧保存先のスキーマ・移行資料（現在のアプリからは接続しません）
- `ensuku-note.html`: note記事プレビュー用HTML

## ローカルで開く

静的HTMLなので、問題演習は `index.html` をブラウザで開けば動作します。ランキングの閲覧・投稿は公開URLからご利用ください。

例:

```text
file:///C:/Users/kobot/Documents/Codex/2026-05-04/files-mentioned-by-the-user-spec/index.html
```

GitHub Pages 上では以下から確認できます。

```text
https://tenten-ensuku.github.io/ensuku-drill-codex/
```

## データ保存

ユーザーの成績、復習、お気に入り、設定は主にブラウザの `localStorage` に保存されます。

ランキング投稿データは専用の Cloudflare D1 に保存され、専用 Worker API を通じて投稿・取得します。公開レスポンスに端末IDは含めません。端末ID・ニックネームは本人認証には使いません。

2026年9月10日に旧Supabaseから移行しました。旧データは当面保全し、他アプリの保存先は変更していません。

## 麻雀牌画像について

麻雀牌画像は、このプロジェクト内の `tiles/` ディレクトリの画像を使用します。

牌画像を使う画面では、原則としてこの画像セットを使用してください。  
外部素材や生成画像への置き換えは想定していません。

## note記事プレビュー

アプリ紹介用の記事プレビューとして、以下のHTMLを用意しています。

```text
ensuku-note.html
```

note投稿前の構成確認や文章調整用です。
